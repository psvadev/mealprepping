# 🧊 Reheat & Eat

A browser-based weekly meal planner for a Norwegian family doing batch-cook meal prep. No server, no build step — just a single `index.html` file served locally.

The philosophy: cook everything on one batch day, freeze in portions, and dinner is just reheating and eating. No per-dinner prep whatsoever.

> **Language note:** The UI, all AI prompts, and all generated content (recipes, suggestions, shopping lists) are in Norwegian bokmål. The codebase is in English.

---

## Features

- **Weekly meal grid** — plan 1–4 weeks, drag-and-drop meals into days; drag between days to swap
- **AI suggestions** — generates meal ideas via the Anthropic API, guided by protein and cuisine targets, prep time limit, and allergen exclusions
- **Allergen check** — the AI is told to avoid your exclusions, and its output is checked again in the browser: recipe ingredients, shopping list items and suggestion cards that look like an excluded allergen get a red ⚠, with Norwegian allergen names understood (e.g. "gluten" also flags hvete, pasta and brød; "laktosefri melk" and "kokosmelk" don't trip a dairy exclusion). A warning, not a guarantee — it can't see hidden sources like gluten in a stock cube
- **Manual meal entry** — type any meal name; AI enriches it with emoji, protein type, cuisine, prep time, and a **batch-friendliness score** (1–5 ❄). Score and a plain-language label ("Ikke egnet for batch" → "Perfekt for batch") appear on the card and in the detail modal so you know before committing whether a dish is a good batch-cook candidate. AI-generated suggestions intentionally omit the score — they're already enforced batch-friendly by the prompt
- **Recipes on demand** — ingredients, steps, and nutrition fetched and cached per meal, and per portion count and unit system, so nudging the portions stepper and back costs nothing
- **Shopping list** — auto-generated by category, scaled to your portion count; freezer-aware (sums the portions you already have of each dish and skips or scales down its ingredients, giving stock to the earliest week first)
- **Real grocery prices** — optional Kassalapp API integration for live Norwegian store prices (falls back to AI estimate)
- **Favourites** — star meals to reuse them across weeks
- **Meal history** — tracks recent meals and tells the AI to avoid repeating them
- **Notes per meal** — free-text notes saved as you type, so nothing is lost if the tab closes
- **Batch day time estimate** — realistic single-time estimate per week using active + passive cooking time split: hands-on prep is counted serially, unattended cooking (oven, boiling) assumes 4 concurrent slots (1 oven + 3 burner simmers); improves as recipes are loaded. Tip: lower the max prep time slider to reduce total batch day duration
- **Weekly nutrition summary** — calories, protein, fat, carbs, and fibre summed per week from cached recipes
- **Cuisine library** — 19 predefined cuisines (Italian, Asian, Filipino, etc.) to set weekly targets
- **Metric / imperial toggle** — switch between g/kg/dl and oz/lbs/cups; recipes are kept per unit system (switching back restores them), shopping lists are rebuilt
- **Print / share** — opens a dark-themed printable page; switches to white for physical printing
- **Freezer tracker** — log a planned week to a freezer inventory; track remaining portions with +/− controls; per-recipe age warnings based on the AI-determined shelf life for that dish (e.g. 60 days for fish, 90 for meat stews) — warns 14 days before the limit and again when expired, so a fish gratin flags well before a beef stew would
- **Meal ratings** — 👍/👎 on freezer items once you've eaten a portion; thumbs up adds to favourites, thumbs down blocks the meal from future AI suggestions
- **Shopping list check-off** — tap items while shopping to strike them through; sub-items (which dish uses each ingredient) collapse when the parent is checked; categories are collapsible to keep the list manageable; progress persists across page refreshes and clears when the list is regenerated. Opening a list never regenerates it behind your back — if the plan changed since, a banner offers to update it, so ticks aren't lost halfway round the shop
- **Batch & freeze tips** — each recipe includes 1–3 AI-generated tips on how to pack, freeze, and reheat the dish
- **Google Drive sync** — optional auto-sync to a single JSON file in your Google Drive; keeps plan, freezer, and recipe cache in sync across devices using OAuth PKCE with `drive.file` scope (no access to other Drive files); an amber badge appears on the Settings tab if the connection drops or a sync fails, so you notice before going to the store with a stale list. Edits made offline are uploaded next time you open the app, and if the same backup changed on another device the app asks which version to keep instead of overwriting one of them — or lets you decide later, pausing sync until you choose. Sign-in problems are explained in Settings
- **Export / import** — save and restore the full plan as JSON; imports show a preview of what will be replaced and can be undone afterwards; export shopping list as `.txt`
- **Undo** — one-tap deletes (clearing favourites or history, removing a freezer item or batch) show an "Angre" button for a few seconds
- **Damaged data is rescued, not lost** — if saved data can't be read, the unreadable copy is kept and offered as a download instead of being overwritten; if the app ever crashes, its rescue screen downloads a file that Import accepts
- **Mobile layout** — responsive design for phones (< 640px): bottom nav bar, compact header, one-week-at-a-time plan grid; desktop controls hidden on mobile

## Requirements

- A modern browser — tested on Firefox, Safari (WebKit, which every iOS browser uses) and Chrome/Edge (Chromium)

| Credential | Required | Purpose | Access granted |
|---|---|---|---|
| [Anthropic API key](https://console.anthropic.com/settings/keys) | **Yes** | All AI features — suggestions, recipes, shopping list | Anthropic API only |
| [Kassalapp API key](https://kassal.app/register) | No | Real Norwegian grocery prices; falls back to AI estimates without it | Product search only (free hobby plan, 60 req/min) |
| Google OAuth Client ID + Secret | No | Drive sync — auto-saves plan to Google Drive so multiple devices stay in sync | Only the single backup file the app created (`drive.file` scope) — no access to email, calendar, or other Drive files |

**Google Drive setup:** Create a project in [Google Cloud Console](https://console.cloud.google.com), enable the Drive API, and create an OAuth 2.0 Web application client. Add `http://localhost:8080/` as an authorised redirect URI. Enter the Client ID and Client Secret in ⚙ Innstillinger, then click "Koble til Google Drive" to log in. Multiple family members can share the same plan by signing in with the same Google account — the `drive.file` scope means the app can only see the one file it created, nothing else in the account.

## Running locally

Any static file server works — the app is a single HTML file with no build step. Python 3 is the easiest option on most systems:

```bash
python3 -m http.server 8080
```

Python 3 is free and available from the [Microsoft Store](https://apps.microsoft.com/detail/9NRWMJP3717K) on Windows. Alternatives: `npx serve`, VS Code Live Server, nginx, or any other local web server.

Open `http://localhost:8080` in your browser, then go to **⚙ Innstillinger** and add your Anthropic API key.

## Tests

Browser tests drive the real app in Firefox, WebKit and Chromium, with Google and the Anthropic API replaced by fakes — no keys needed, and no real API calls are made:

```bash
pip install playwright
python -m playwright install firefox webkit chromium
python tests/run_all.py
```

Run them before committing anything that touches storage, import/export or Drive sync. See [CLAUDE.md](CLAUDE.md) → Tests for what each suite covers.

## Architecture

| Aspect | Detail |
|--------|--------|
| Stack | React 18 + Babel Standalone via CDN — JSX transpiled in-browser |
| State | All state in `localStorage` with `mp_` prefix — no backend |
| AI | Anthropic API called directly from the browser (`anthropic-dangerous-direct-browser-access: true`) |
| Model | `claude-sonnet-5` (thinking disabled) |
| Prices | `kassal.app/api/v1/products` — optional, falls back to AI estimate |
| Sync | Google Drive OAuth PKCE (`drive.file` scope) — optional, auto-saves plan JSON across devices |
| Security | CDN scripts pinned to exact versions with SRI hashes; Content-Security-Policy limits scripts to unpkg and network calls to Anthropic, Kassal and Google; Google sign-in uses PKCE plus a checked `state` |
| Tests | Python + Playwright in `tests/` — no Node; the app itself stays build-free |

See [CLAUDE.md](CLAUDE.md) for full technical documentation.
